# Bếp Nhà — Website công thức nấu ăn

Mã sinh viên: DTC245200656
Môn học: Triển khai và quản trị hệ thống phần mềm

## Chức năng
- Xem danh sách và chi tiết công thức.
- Tìm kiếm món ăn, lọc theo danh mục.
- Đăng nhập và đăng xuất quản trị.
- Thêm, sửa, xóa công thức.
- Quản lý nguyên liệu và các bước nấu.

## Môi trường hiện tại
- PHP 8.2 trên XAMPP.
- MariaDB và phpMyAdmin.
- Website: http://localhost/recipe/
- Quản trị: http://localhost/recipe/admin/login.php
- Cổng database trên máy phát triển: 3307.

## Tiến độ
- Đã hoàn thành chức năng website trên XAMPP.
- Chưa hoàn thành bản triển khai Docker Compose.
- Các phần tiếp theo: MySQL, Nginx reverse proxy,
  Prometheus, Grafana, Loki, Promtail và hardening.

## Dữ liệu
Bản sao lưu database được giữ riêng, không đưa lên Git.
Hướng dẫn khởi tạo dữ liệu sẽ bổ sung cùng bản Docker Compose.
